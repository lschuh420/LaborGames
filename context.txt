# PROJEKT-KONTEXT (AAA Spinnen-Mech Bossfight)
Ich entwickle einen 3D-Bossfight in Unity. Der Boss ist ein massiver Spinnen-Mech mit Inverse Kinematics (IK) für die Beine. Der Spieler nutzt einen First-Person/Third-Person Controller und feuert physische 3D-Kugeln (M1911), die beim Aufprall über ein Interface (`IDamageable`) Schaden austeilen.

# AKTUELLER ARCHITEKTUR-STATUS
- **Damage System:** Ein globales Interface `IDamageable` mit `void TakeDamage(int damage)`.
- **Waffen:** `PlayerBullet.cs` (3D-Kugel mit Rigidbody) nutzt `OnCollisionEnter`, sucht das Interface und teilt Schaden aus.
- **Boss KI (`RobotCombatMaster.cs`):** Behavior Designer State-Machine. Erkennt Spieler auf 12m, friert ein, lädt 1.5s auf und feuert.
- **Boss Angriff (`MechDefenseField.cs`):** 30m 3D-Mesh-Partikel-Nova. Zieht Spielern im Radius via `OverlapSphere` und `IDamageable` massiv HP ab.
- **Boss Leben (`MechBossHealth.cs`):** Das Haupt-Skript auf dem Root-Objekt. Der Boss hat aktuell eine Methode `TriggerMechDeath()`.

# FEATURE-ANFORDERUNG: HITBOX & DESTRUCTION SYSTEM
Dein Ziel ist es, das Schadensmodell des Mechs auf AAA-Niveau umzubauen. Die Boss-HP werden auf 2500 erhöht. Der Rumpf ist gepanzert, die Beine und der Rücken haben gelbe Schwachstellen.

Implementiere folgende Logik durch modulare Skripte (z. B. ein `DamageRouter.cs` für Hitboxen):

1. **Rüstung & Schwachstellen (Multiplier):**
   - Treffer auf den gepanzerten Hauptkörper (Rumpf) machen nur 0.5x Schaden.
   - Treffer auf die gelben Punkte an Beinen und Rücken machen 1.5x bis 2.0x Schaden.
   - Jeglicher Schaden wird an das zentrale `MechBossHealth`-Skript weitergeleitet und von den 2500 HP abgezogen.

2. **Bein-Zerstörung (Lokale HP):**
   - Jedes Bein hat zusätzlich eine eigene interne Lebensleiste (z. B. 300 HP). 
   - Fällt die Bein-HP auf 0, gilt das Bein als zerstört. 
   - **Visuelles Feedback:** Das Bein fällt simpel in Einzelteilen zu Boden (einfache Schwerkraft/Trennung der Meshes), begleitet von einer kleinen Partikel-Explosion. Die IK für dieses Bein wird dauerhaft deaktiviert.

3. **Stun-Mechanik (Das erste zerstörte Bein):**
   - Wenn das erste Bein weggeschossen wird, stürzt der Mech physikalisch/animiert zu Boden.
   - Der Movement-Teil des Behavior Trees wird für 3 Sekunden gestoppt (Stun-Timer).
   - **WICHTIG:** Während er am Boden liegt, ist er NICHT wehrlos! Das Skript für die Energie-Nova (`MechDefenseField.cs`) kann weiterhin auslösen.

4. **Critical State (Das zweite zerstörte Bein):**
   - Verliert er ein weiteres Bein, steht er zwar wieder auf, aber sein Movement-Speed wird permanent massiv verringert (humpeln/instabil).
