# Brainstorming Skill

## Overview
This skill is used for creative planning and architectural design. It ensures that we "cook" the best possible features and "juggle" complex systems with precision.

## Workflow
1. **Understand Intent**: Clarify what we are trying to achieve (the "cüsss" factor).
2. **Explore Options**: Discuss different technical approaches.
3. **Refine Requirements**: Define the exact functionality and constraints.
4. **Draft Plan**: Create a high-level strategy before diving into the code.

## Guidelines
- Stay focused on AAA quality.
- Prefer modular, component-based architectures.
- Always think about the player experience.
